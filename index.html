ACCIDENT

A benchmark dataset for accident detection from traffic surveillance videos.

ACCIDENT is designed for evaluation in supervised, few-shot, and zero-shot settings. The benchmark focuses on three core tasks: temporal localization, spatial localization, and collision type classification in challenging CCTV footage.

Project overview Benchmarks
  • 2,027 curated benchmark clips described in the abstract
  • Real-world CCTV footage with temporal, spatial, and type annotations
  • CARLA-based synthetic generation pipeline for data-scarce settings

Representative real-world clips across viewpoints, weather, quality, and collision types.

Overview

A project website first, a leaderboard hub second

Why this benchmark

Most accident understanding work is built around dashcam data or narrow CCTV collections. ACCIDENT is structured around difficult surveillance footage and supports broader evaluation regimes, including zero-shot and few-shot settings.

The website is drafted to present the paper clearly while also leaving room for multiple benchmarks, evaluation tracks, and evolving code releases.

Core tasks

  • Temporal localization: when the accident happens.
  • Spatial localization: where the accident occurs in the frame.
  • Collision type classification: what type of event is observed.

Benchmark Design

Multiple tracks are built into the website structure

Track A

Zero-shot evaluation

For foundation models and VLMs tested without task-specific training on ACCIDENT.

Track B

Few-shot adaptation

For methods that adapt with limited labeled data and must remain robust to scarcity.

Track C

Fully supervised

For conventional training with benchmark splits and standardized evaluation protocols.

Track D

Sim-to-real transfer

For models leveraging synthetic accident generation to improve real CCTV performance.
