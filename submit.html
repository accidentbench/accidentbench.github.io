Submission Instructions

Submission Guide

Submit To The Leaderboard

Use a GitHub pull request to submit results, attach method metadata, and get an automatic score preview before merge.

How submission works

The ACCIDENT benchmark uses GitHub pull requests for submissions. Each submission PR should add exactly one CSV file under the correct benchmark folder and fill out the standardized method metadata block in the PR template.

The PR workflow scores the submission automatically and comments the result. After merge, the leaderboard workflow updates the benchmark leaderboard data.

Submission Steps

GitHub-based flow
  1. Create a branch in the repository or a fork of the repository.
  2. Add your CSV file under one of these folders:
    submissions/iid/ submissions/geo-aware/ submissions/zero-shot/
  3. Name the file something stable, such as team-name.csv or method-name.csv.
  4. Open a pull request against main. GitHub will prefill the PR template automatically.
  5. Fill in the metadata block with method name, authors, affiliation, paper link, code link, contact email, benchmark, and a short description.
  6. Wait for the PR scoring workflow to comment the score preview.
  7. After review and merge, the leaderboard update workflow will process the result.

In-distribution Submission

Put your file under submissions/iid/. This benchmark corresponds to the standardized split of the real dataset.

Out of Distribution Submission

Put your file under submissions/geo-aware/. This benchmark targets generalization under region shift.

Zero-shot Submission

Put your file under submissions/zero-shot/. This benchmark targets methods that operate without benchmark-specific labeled training data.

CSV Format

Your CSV must contain the following columns:

path accident_time center_x center_y type

You can use the sample file already in the repository as a reference.
